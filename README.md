# SC-200 Prep Hub

A personal study site for Microsoft exam SC-200. The questions are original, and aren't real exam questions.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Choose **Add file > Upload files**, and upload everything in this folder, including `.nojekyll`.
3. Go to **Settings > Pages**, set the source to **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Open the address GitHub shows after a minute or two.

## Add it to your phone
Open the site once with a connection. It then works offline.
- **iPhone (Safari):** Share > Add to Home Screen
- **Android (Chrome):** menu > Add to Home screen

To update the site later, upload the changed files again.
